D018 | 2026-11-15 | Supersedes the fixed-priority clause of D010. Memory port = strict time division: free-running 2-bit slot counter, engine Ei owns every clock with slot = i (one fetch or table access per engine per 4 clk; an unused slot may serve the host, never another engine); 1-instruction prefetch buffer per engine; instructions execute only from the instruction register. Guaranteed on every engine regardless of the others: prefetched successor armed 1 clk after a guard fires (always if the firing instruction was armed ≥4 clk); otherwise request → armed in 2–5 clk, worst case 5 = 3 slot wait + 2 read; j un-prefetched words ≤ 4j+1 clk; table access 2–5 clk | fixed priority E0>E3 (bound for E1–E3 depends on other engines' programs; E0 special); work-conserving round-robin (same worst case, better average, but an engine's timing would depend on its neighbours' activity: no per-program bound, no isolation); execute-from-SRAM bypass (saves 1 clk, puts 6.3 ns back on the execute path); dual-port macro | fixed latency → the assembler bound is static per program (4 clk per un-prefetched word + 1) and the grant is provable as grant_i ⇔ slot = i; engines are timing-isolated, so a program verified alone stays valid in any mix | ≈60 cells/engine; unguarded code 1 instruction per 4 clk (E0 was 1 per clk); execute path ≈14 → ≈8 ns | all; figures for SPI target, UART RX, I2C target in docs/history/ARCH_CANDIDATES.md §10.5
D019 | 2026-11-15 | Guard events are latched (amends D012, closes the "instantaneous vs latched" question): per engine one sticky flag per event (rise/fall of 4 logical pins, tick, tock); set while the engine is busy (fetching, executing, memory access), consumed by the guard that names it, held clear while a guard is armed and waiting; a late instruction answers late, never misses. Each flag records a second event; a guard consuming such a flag sets the engine's sticky overrun flag (host-visible, program-testable). Host data = FIFO level, a byte at a full FIFO sets the same flag. Timer restart clears the tick/tock flags | instantaneous events (an edge is lost if its guard is not loaded yet); flags that also latch while a guard waits (data edges of one UART frame fire the next start guard and raise overrun every frame; a program flush races with a real edge); overrun raised on arrival (false alarms from events the program is not waiting for) | fetch latency (D018) may delay a response but must not drop an edge; overrun is the run-time witness of the assembler's static bound | ≈80 cells/engine (21 flops) | all edge- and timer-driven roles: SPI/I2C target, UART RX, Manchester RX, monitor
