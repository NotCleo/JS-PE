# RTL_REVIEW — src/*.v against ARCH / ISA / HOSTIF / PINS (2026-11-18)

Scope: every file in src/ at bf915ea. Focus: engine↔arb↔mem, link↔fifo↔engines, pad ownership / OE / open-drain, signal flags, reset and reload mid-run, STOP/EXEC races, X sources, test gaps against VERIF_PLAN.
Method: line-by-line read against the spec; each corner traced through the RTL and through sw/jspe_iss.py (the RTL follows the ISS clock for clock, so ISS = RTL is checked as well as spec = RTL); then a new random full-chip lockstep test (F1), checked with five seeded glue bugs.
Severity: **H** = wrong behaviour a host or program can reach; **M** = reachable spec violation with a workaround, or a MUST without verification; **L** = unreachable, documentation, or style.

**Result:** no H or M defect in the RTL. Twelve L items (spec gaps, 1-clk races, one ISS-only difference under host misuse) and one M test gap, closed by F1. No RTL file changed: synthesized area delta 0 (445 495.1 µm², `make area`, sg13g2 typ).

## Checked and clean
- **engine↔arb↔mem.** `req`/`addr` never depend on `gnt` (jspe_seq.v:204–212), grant is combinational (jspe_arb.v:35–37): no loop, one access per clock, host only in a slot whose owner does not request. A request is withdrawn while the engine is not active and raised again after RUN (`act` in `mem_req`, `other`, `req_red`, `fold_pre`); a granted access finishes while stopped (`ld_done` and the fetch capture do not use `act`, :173, :195–196). A watcher cancels `ld`/`st` up to the completion clock (`mo_now` has `~wf`, :170); a store in a watcher clock is not requested, so not written. `ld`/`st` operands are stable while pending (nothing writes R0–R2/S/P/C without a fire). Flop memory is read-before-write across clocks, like the macro.
- **link↔fifo↔engines.** FIFO limits follow the registered levels on both sides; engines never push full or pop empty (jspe_engine.v:108, 111; jspe_shift.v:82), the link pops only a non-empty current stream (jspe_link.v:306, 352–361). `rx_ovf` > `clr_ovr` > engine set (D065) in RTL and ISS. Engine pulses (`RST`, `RUN` …) come one clock after a stop sample, so they never coincide with an `rx_wr`. H_RDY from the next parser state, next selection and registered `free` (:371–373) = HOSTIF 1 / D080. EXEC/RUN/STEP/SLOTMAP checks (:142–146) read registered status; nothing can change it between the check and the pulse (commands are ≥ 10 B apart). `exec_word = {b, a0}` (:251) is stable ≥ 1.5 B after the pulse. Escape sequences are never interleaved (`b2v` first); notices and replies do not change the current stream.
- **Pins.** One 16:1 owner mux per pad from the host-only PAD register (jspe_pins.v:65, 74–77): two engines can never drive one pad. `od` never drives 1 (`uio_out` = 0, `oe = o & ~v`); `en` = 0 → 0 and released (monitor guarantee); PAD[4], PAD[5] neither stored nor writable (jspe_link.v:178); pads registered, reset 0x10 / 0 / 0 (jspe_pins.v:81–91). One shared 2-FF synchronizer; the link reads the unfiltered level (tt_um:79, D076).
- **Signal flags.** `(G | S) & ~C`, host write replaces (jspe_sig.v:19–20); engines see a flag one clock after the request, through bind sources 16–23 with edges like a pin.
- **Reset and reload.** `rst_n` through 2 FF into a synchronous reset (tt_um:17–19); after 3 edges with `rst_n` low the pads are 0x10 / 0 / 0 (VERIF 6 top property holds by inspection; H5 exercised by F1). `RST e` flushes both FIFOs and keeps R0–R2/S/P/C/T (ARCH 9.1), in RTL and ISS. Host writes use only slots whose owner does not request, so running engines keep their timing.
- **STOP / EXEC.** STOP cancels a pending injection with its waiting or in-flight `ld` (jspe_seq.v:313–322); EXEC drops PF, HR, an in-flight read and a waiting `ld`/`st`, FP ← PC + 1 (:200–201, :328–336); an `ld` completing in the EXEC clock advances PC first, so RUN resumes after it. Trap and STOP end step mode, RUN clears `halted`. Deviations: F6, F7 only.
- **X sources.** Unreset flops: `rst_s` (the synchronizer); jspe_pins `s1 s2 h1 h2` (fill in 2–4 clk during reset); jspe_link `rx_sh op a0 a1 pm wr_paddr wr_pdata rp_word rp_kind rd_addr tx_sh b2`, each read only under a reset-cleared qualifier — the outputs `exec_word`, `pad_idx`, `pad_wdata`, `sig_wdata`, `rx_wdata`, `h_addr`, `h_wdata` may be X while their strobe is 0 and every consumer gates them (AND-OR in jspe_arb, `if (pad_we && …)`, `if (sig_we)`, FIFO `ld` from `push`, IR load on `exec_p`); jspe_fifo data (head read only when non-empty); jspe_seq `ir hr pf` (valid bits); memory, R0–R2, S, P, C, T, LFSR, POLY (undefined by ARCH 9.1: a program or host that reads them first sees X in RTL, 0 in the ISS — F1 initialises them). No X reaches a pad from reset onward (F1 fails on X).
- **RTL rules.** `make lint` clean; every `always @(*)` assigns defaults first (no latches); registered pads; no `initial`, `casex`, delays; one module per file.
