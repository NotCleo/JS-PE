# formal/ PLAN (Phase 8, VERIF_PLAN 6)

## Method
- Tools: `~/tools/oss-cad-suite` (sby/yosys 0.70). `make formal B=<block>` runs `formal/<block>.sby` → property, result, depth; results in `RESULTS.md`.
- `formal/fv_<block>.v` wraps the unmodified RTL (src/ frozen). Internals via yosys `expose` in the .sby script (open yosys has no `bind`), abstractions via `cutpoint`.
- Tasks: `prove` (abc pdr, else k-induction), `bmc` (yices, depth recorded), `cover`. Inputs free, reset in step 0; assumptions only where another block proves them.
- Failures: RTL bug → bug-fix commit with area delta; spec issue → stop and ask.

## Blocks (priority order)

1. **arb** (prove): `e_gnt[i]` = `e_req[i]` ∧ owner i; ≤ 1 grant incl. host; `h_gnt` ⇒ owner not requesting; `mem_*` = granted client's, `mem_en` ⇔ grant. Any map: a held request of engine i is granted within G_i − 1 clk (0xE4: 3). Covers: every client granted, host in an unused slot.

2. **seq** (bmc ≥ 40, pdr where it closes)
   - Fetch latency (`gnt` = `req` ∧ own slot, symbolic map and phase): IR refill request → armed at g + 2 (g = first own slot), ≤ G + 1 (5 default, 2 solo) unless a redirect or host pulse intervenes; request and address held until granted; no read while one is in flight except a redirect; nothing fetched before a redirect is armed after it; armed ≥ G clk, completing without redirect, not `ld`/`st`, successor not `jmp`/`jmpa` ⇒ successor armed at f + 1 (D100 credit).
   - Events/OVR: inactive ⇒ no fire, no request, F = D = 0; a live event in a busy clock is consumed, latched or doubled, never dropped; no flag survives a waiting clock; OVR rises only on a consumed doubled flag, `push`/`evt` on full TX, `pull` on empty RX, `rx_ovf`; falls only by `ovclr` (not with a doubled consume), host clear, reset.
   - Watcher fires only enabled, rising, running; blocks that fire. Trap: run 0, PC kept; halt: PC = next.
   - Decoder: `undef` equals the isa.yaml predicate for all 2^16 words; `f_*` = yaml formats, which partition the words. Predicate from new `sw/gen_isa.py --fv` (under `--check`).

3. **pins + epins** (prove, no environment assumptions: every input free)
   - pins (fv_pins.v; PAD registers renamed + exposed in pins.sby): PAD[j] = 0 after reset, changes only by its own `pad_we` and takes `pad_wdata` (uo: no `od`; 4, 5: no register); every pad register = the ARCH 2.1 function of PAD[j] and its owner's `e_val`/`e_oe` one clock earlier (ownership: nothing else reaches the pad); `en` = 0 ⇒ out 0, oe 0 (monitor guarantee); `od` ⇒ uio out 0, never oe ∧ out; `uo_out[4]`/`[5]` = H_TX/H_RDY 1 clk later (reset 1/0); `lvl_raw` = pad 2 clk earlier; FILT = 0 ⇒ `lvl` = `lvl_raw`; FILT = 1 ⇒ `lvl` = the sample after three equal samples, else the previous filter output (filter runs whatever FILT holds, D076); filtered level changes only after three equal samples (black box).
   - epins (fv_epins.v; `bnd`, `fol` exposed; previous level black box): BIND01/23 = 0 after reset, written only by their `wcfg` with `opb[5:0]`/`opb[13:8]`; level = source ^ invert with the ISA 5 source numbering; rise ∧ fall never; edges = level change vs the previous clock (0 after reset), none in the clock after a write to the pin's BIND register; `val`/`oe`/`fol` against a transcription of ISA 8.1 step 2 + ISA 7 follow (A then B, B wins, `z` keeps val, `t` toggles and ends follow); follow takes `dcur` unless an action names the pin; `oe`/`fol` change only when an E action names the pin, `val` also by follow.

4. **fifo** (prove, W 8 and 9 by `hierarchy -chparam` per task; `v`, `m1`–`m3` exposed; flush in step 0 = engine reset, every other input free): `v` a thermometer from the head (count ≤ 4); `empty`/`full`/`free` = count 0 / 4 / 4 − count; count' = count + push − pop with push = `wr` ∧ count < 4, pop = `rd` ∧ count > 0 (limits on the registered levels, D046); a write to a full FIFO is ignored also with a pop in that clock; a pop of an empty FIFO is ignored also with a write in that clock; flush empties; tracked word (free choice of any pushed word): head and `rdata` after exactly as many pops as entries were ahead of it (helper: it sits at entry `ahead`).

5. **link** (prove by k-induction where it closes, else bmc with the depth recorded; every input free incl. the host bit stream `h_rx_s` at any timing, so nothing proven depends on host behaviour; engine side only as seq proves it without the link env: `run` rises only after RUN/STEP (a_run_up), `xm` only after EXEC (new a_xm_up); `h_gnt` ⇒ `h_req` (arb a_hgnt)). Sub-steps:
   - A. D107 obligations at the pulse clock: `e_exec[e]` ⇒ ¬run_e ∧ ¬xm_e; `e_run`/`e_step[e]` ⇒ ¬xm_e; at most one pulse kind per engine per clock (helper: in a pulse clock the receiver is idle, so two command clocks are never adjacent).
   - B. Framing against a byte-level HOSTIF 2–3 parser model fed by the receiver's accepted bytes (ESC, op, fixed raw args, WRMEM words; break → data state): data-byte, command and op-error strobes; command effects one clock later (SEL; STOP/RUN/STEP/RST masks with the HOSTIF 9 refusals; EXEC word = its two args); ≤ 1 `rx_wr` per clock, to the selected stream only; `rx_ovf` = a write toward a full FIFO; SLOTMAP changes only by WRREG with all engines stopped and without xm.
   - C. H_RDY (D080) = registered (model state data or after ESC) ∧ stream selected ∧ its free < 2. Chip → host escapes: the code byte is the next byte loaded after its ESC (never interleaved) and a valid code; stream data 0x1B → ESC 0x1B, events → ESC 0x40|c, other data raw; data only from the current stream, which changes only with ESC e. Memory request held until granted.

6. **top** (arbitrary initial state: no initial value assumed for any design flop): prove with every block but the pins and the top glue cut to free outputs: `rst_n` low 3 clk earlier ⇒ `uo_out` = 0x10, `uio_out` = `uio_oe` = 0; after a reset pad j drives nothing (uio oe 0, out 0; uo 0) until a PAD[j] write with `en` = 1 (= enabling `pad_we`, tied to the host's WRREG bytes by link a_reg); bmc 40 with the whole chip minus the memory: reset 3 clk, then H_RX idle ⇒ all pads at reset values (H_TX 1, H_RDY 0).

7. **timer, shift, sig, lfsr** (prove, every input free; one per response):
   - timer (fv_timer.v; `tcfg`, `fa`, `psc`, `trun`, `tone`, `skip` exposed): next state against a transcription of ARCH 7 (prescaler step, skip, count, one-shot stop, periodic reload with FA carry, starts and their priorities incl. D084, TCFG/P/C writes, reset; PSC compared while running); tick ⇔ trun ∧ st ∧ ¬skip ∧ T = 0, tock likewise with T = C; T counts down by one per enabled clock; one-shot stops after its tick unless restarted; a start loads T, clears FA, PSC, skip and wins over the count step and `tstop`; windowed sync only when stopped or T < C; ARCH 7 timing with `pre` = 0: start with value V in clock k ⇒ tick in k + V + 1, tock in k + V − C + 1.
   - shift (fv_shift.v; `shcfg`, `tapcfg`, `n`, `runl`, `lvq`, `ldq` exposed): next state and the outputs used by epins/seq/FIFOs against a transcription of ISA 7 + ISA 8.1 steps 1–3 (sample shift, out shift with fill 1, one shift per instant, tapped bit, B/RUN/PAR incl. the stuff tap of `q` with ALT 2, LD, LV, N, wend, auto-transfer with `ok`, LFSR step, wrst / SHCFG write side effects, TAPCFG, S writes, reset); named: bits above the word 0 after a shift without pull; N ≤ wl; at most one shift per instant (`out` with `shin` shifts once); auto-transfer strobes only at wend with every enabled FIFO able; `smp` changes neither S nor N.
   - sig (fv_sig.v, every input free, any request bits): next G = ARCH 2.6 (`(G | S) & ~C`, S and C ORed over the four engines, a host write replaces the result, reset 0); named: clear wins over set from any engine; a host write replaces the engine result of its clock; a set without a clear makes the flag 1; a flag changes only by a set, a clear, a host write or reset.
   - lfsr (fv_lfsr.v; `poly`, `right` exposed; every input free incl. indices 5–7): next state against ARCH 2.7 for a symbolic LFSR and POLY in both forms (left: fb = bit ^ L[31], L' = (L << 1) ^ (fb ? POLY : 0); right: fb = bit ^ L[0], L' = (L >> 1) ^ (fb ? POLY : 0)); named: any write (any index, any engine) blocks every step; of several writes only the lowest engine's acts; of several steps the lowest engine's bit is used; `right` resets to 0; LFSR and POLY are not compared in a clock after a reset clock (ARCH 9.1: not reset, undefined until written).
